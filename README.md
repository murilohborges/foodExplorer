# Food Explorer - Frontend

Este é o frontend do projeto **Food Explorer**, um sistema para pedidos de pratos, desenvolvido como parte do aprendizado na Rocketseat.

## 📂 Estrutura do Projeto

A estrutura de diretórios do projeto é organizada da seguinte forma:

```
foodexplorer/
│-- src/
│   │-- assets/          # Arquivos estáticos (imagens, ícones, etc.)
│   │-- components/      # Componentes reutilizáveis
│   │-- context/         # Context API para gerenciamento de estado global
│   │-- hooks/           # Hooks personalizados
│   │-- pages/           # Páginas principais da aplicação
│   │-- routes/          # Definição das rotas da aplicação
│   │-- services/        # Serviços de requisições HTTP
│   │-- styles/          # Estilos globais
│   │-- utils/           # Funções utilitárias
│   │-- main.jsx         # Arquivo principal
│   │-- App.jsx          # Componente raiz da aplicação
│-- public/              # Arquivos estáticos públicos
│-- index.html           # HTML base da aplicação
│-- package.json         # Configurações do projeto e dependências
│-- vite.config.js       # Configuração do Vite
```

## 🚀 Tecnologias Utilizadas

- **React**: Biblioteca principal para construção da interface.
- **React Router DOM**: Gerenciamento de rotas no frontend.
- **Styled Components**: Estilização dos componentes.
- **Axios**: Consumo de API.
- **Material UI**: Componentes de UI modernos e responsivos.
- **Swiper**: Carrosséis interativos.
- **Vite**: Ferramenta de build e desenvolvimento rápido.

## ▶️ Como Executar o Projeto

Para rodar o projeto localmente, siga os passos abaixo:

1. Instale as dependências:
   ```sh
   npm install
   ```
2. Inicie o servidor de desenvolvimento:
   ```sh
   npm run dev
   ```

O projeto será iniciado e poderá ser acessado pelo navegador em `http://localhost:5173/` (ou outra porta definida pelo Vite).
